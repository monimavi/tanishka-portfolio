# Tanishka — Full Stack Web Developer Portfolio

Original Next.js + Tailwind implementation inspired by the visual rhythm of a premium dark developer portfolio, rebuilt from scratch for Tanishka's real work and content.

## Run locally

```bash
npm install
npm run dev
```

## Contact form
Create a Web3Forms access key and add it to Vercel as:

`WEB3FORMS_ACCESS_KEY=your_key`

## Deploy
Push the project to GitHub. Vercel will detect Next.js automatically.
